# Мониторинг цен конкурентов

Демо-проект парсера: магазин «ТехноДом» сравнивает свои цены с тремя конкурентами, хранит историю за 30 дней
и показывает изменения за сутки.

**Demo:** https://price-monitor-demo.netlify.app

## Почему тестовые магазины
Публичная демка не должна парсить чужие сайты, поэтому три конкурента это тестовые магазины внутри проекта.
Их цены каждый день меняются по детерминированной модели: колебания, акции, товар пропадает из наличия.
У каждого магазина своя разметка, как в жизни:

| Магазин | Разметка | Как парсим |
|---|---|---|
| МегаТех | карточки товаров | CSS-селекторы |
| Цифра+ | таблица прайса | строки таблицы, цена из атрибута `content` |
| ЭлектроМир | цена рисуется JavaScript | структурированные данные JSON-LD (schema.org) |

Четвертый источник — реальный внешний сайт [books.toscrape.com](https://books.toscrape.com), созданный для тренировки парсинга.

## Что умеет
- Сопоставление товаров по таблице артикулов (у каждого магазина свои названия и коды)
- История цен за 30 дней, график по каждому товару
- Лента изменений: подешевел, подорожал, закончился, снова в наличии
- Позиция нашей цены относительно минимальной у конкурентов
- Запуск по расписанию (Vercel Cron, 09:00 МСК) и по кнопке с логом прогона
- Выгрузка в CSV (открывается в Excel)
- Падение одного источника не ломает прогон, ошибка видна в логе

## Стек
- **Парсер и API:** Python 3.12, FastAPI, httpx (асинхронно), selectolax, Upstash Redis
- **Дашборд:** Next.js 14, TypeScript, Tailwind CSS (статический экспорт), график на SVG без библиотек
- **Хостинг:** API на Vercel, дашборд на Netlify с проксированием `/api/py/*`

## Локальный запуск
```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt uvicorn pytest
.venv/Scripts/python -m pytest tests
.venv/Scripts/uvicorn api.index:app --port 8000

cd web && npm install
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8000/api/py npm run dev
```
